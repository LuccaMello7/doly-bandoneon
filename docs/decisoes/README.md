# Decisões de arquitetura

Cada arquivo registra uma decisão grande: o contexto, o que foi decidido, as alternativas e as consequências.
Uma decisão não é apagada quando muda: ganha um registro novo que a substitui, e a antiga diz "Substituída por".

Quando escrever um: antes de trocar uma invariante do [ARCHITECTURE.md](../../ARCHITECTURE.md), de acrescentar
um serviço de fora, de mudar onde um dado mora ou de criar uma dependência nova.
