# Requisitos de iniciativas

Um documento por iniciativa grande, escrito **antes** de começar, curto (uma ou duas páginas). Ele responde
por que e para quem; o como fica no código e, se mudar a arquitetura, num registro em `docs/decisoes/`.
O retrato do produto inteiro está em [PRODUCT.md](../../PRODUCT.md).

Quando escrever: funcionalidade nova que leva mais de uma sessão de trabalho, que mexe com dados de pessoas
ou que muda o que o app promete.

Modelo: copie [0000-modelo.md](0000-modelo.md) com o próximo número. Ao terminar, mude a situação para
"Entregue" e anote o que ficou diferente do planejado.
